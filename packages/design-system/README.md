# @oliveiraswell/ds

Design tokens and primitives shared by Remote Engineering Radar applications.

```css
@import 'tailwindcss';
@import '@oliveiraswell/ds/theme.css';
@source '../node_modules/@oliveiraswell/ds';
```

```tsx
import { cn, PageTitle } from '@oliveiraswell/ds';
```

The theme reads `--font-inter` for `font-sans`; load Inter with `next/font` under that variable.
